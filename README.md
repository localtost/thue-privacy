# Thue — Privacy Policy site

Static page for the App Store «Privacy Policy URL»: https://localtost.github.io/thue-privacy/privacy/

- `privacy/index.html` — the policy in English, Russian and Ukrainian (no scripts, no cookies).
- Source text lives in the app repo: `localtost/thue-ios` → `docs/privacy/privacy-policy.md`. Edit both together.
- Deployed by `.github/workflows/pages.yml` on every push to `main` (Settings → Pages → Source: GitHub Actions).
